Install from a terminal

macOS and Linux. Installs the Omniplex server to ~/.local/bin; run omniplex and open the URL it prints. No desktop app, no start at login.

curl -fsSL https://raw.githubusercontent.com/asiraky/omniplex/main/scripts/install.sh | sh

Or download a server tarball from the list above, check it against SHA256SUMS, and put the omniplex binary on your PATH.
